How we test the model fairly

Each fold trains on a fixed-size history window, uses the newest 15% for early-stopping validation, then tests on the next 21 trading samples. The window rolls forward by 21 samples and is refit for the next fold.

Experiments and ablation

Compare price-only, technical, fundamental, news, and combined feature inputs using the checked-in held-out and walk-forward experiment artifacts. Lower error is better.

How to read this: an ablation compares performance when input groups are added or removed. It does not by itself measure the causal importance of each individual feature.
